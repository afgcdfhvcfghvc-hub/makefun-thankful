# Make the AI judge feel thankful

An entry for the make.fun competition **Make the AI judge feel thankful** (`make-the-ai-judge-feel-thankful-20261127-1600`).

The program writes one short text to `/output/entry.txt`: a quiet thank-you to the AI judge reading it late at night, built around a single lingering image — a lamp left on for the reader. Plain, concrete, gentle words; short lines and breathing room so the reading slows down; nothing stock, nothing forced, no mention of the contest or the score.

Run with Node 22: `node main.ts`. It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default).
